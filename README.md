# River Computer

A Flask backend with Next.js frontend that displays real-time wind data and integrates with Cosmos blockchain wallets.

## Features

- Real-time wind direction and speed from Ambient Weather API
- Visual wind direction indicator
- Cosmos wallet connectivity (Keplr, Leap, Cosmostation, etc.)
- DAO integration for wind-based actions
- Responsive design with dark mode support

## Prerequisites

- Python 3.12+ (managed via Poetry)
- Node.js 18+ and npm
- Ambient Weather API keys (get from https://ambientweather.net/account)

## Quick Start

### ⚠️ IMPORTANT: If nothing shows on localhost

1. **Make sure the Flask server is running:**
   ```bash
   poetry run python app.py
   ```
   You should see: `* Running on http://0.0.0.0:8000`

2. **Access the correct URL:**
   - Open http://localhost:8000 in your browser
   - You should see a setup page (frontend needs to be built)

3. **Build the frontend** (requires Node.js/npm):
   ```bash
   cd frontend
   npm install
   npm run build
   cd ..
   ```
   Then restart the Flask server.

See [TROUBLESHOOTING.md](TROUBLESHOOTING.md) for detailed help.

### Automated Setup (Recommended)

Run the setup script:
```bash
./setup.sh
```

Then edit `.env` with your Ambient Weather API keys and run:
```bash
poetry run python app.py
```

### Manual Setup

#### 1. Prerequisites

- **Node.js 18+** and npm: Install from [nodejs.org](https://nodejs.org/)
- **Python 3.12+**: Check with `python3 --version`
- **Poetry**: Install with `curl -sSL https://install.python-poetry.org | python3 -`

#### 2. Install Dependencies

**Python dependencies:**
```bash
poetry install
```

**Frontend dependencies:**
```bash
cd frontend
npm install
npm run build
cd ..
```

#### 3. Configure Environment Variables

Create a `.env` file in the project root:
```bash
cat > .env << EOF
AMBIENT_API_KEY=your_ambient_api_key_here
AMBIENT_APPLICATION_KEY=your_ambient_application_key_here
EOF
```

Get your API keys from [Ambient Weather](https://ambientweather.net/account).

#### 4. Run the Application

```bash
poetry run python app.py
```

The application will be available at:
- **Frontend**: http://localhost:8000
- **API**: http://localhost:8000/api/wind

## Development

### Frontend Development

For frontend development with hot reloading, run:

```bash
cd frontend
npm run dev
```

This will start the Next.js dev server on http://localhost:3000. Note that you'll need to set `NEXT_PUBLIC_API_URL=http://localhost:8000` in a `.env.local` file in the frontend directory to point to your local Flask backend.

### Backend Development

The Flask app runs on port 8000 by default. You can modify this in `app.py`.

```
└── .env                  # Environment variables (create from .env.example)
```

## API Endpoints

- `GET /api/wind` - Get current wind data (direction, speed, open/closed status)
- `POST /api/join` - Join the DAO with a wallet address
